# Primary metric: summed database-call RTT

For each request sum command receipt to complete response delivery, including database execution and communication and excluding application gaps between commands. A MySQL CALL contributes exactly one inclusive outer exchange. PostgreSQL prepare-only exchanges contribute duration but are counted separately from SQL executions. Application method latency and server-only phase sums remain secondary.

The existing rich traces provide diagnostic coverage of 61/160 exact littleX case/arm cells, plus five auxiliary standalone paged-feed profiles. Missing exact profiles, compiler-stage failures and quarantined emoji-encoding profiles are distinct categories. Legacy traces include a 2 ms injected response delay and per-frame tracing overhead; they do not replace fresh compact measurements.

The shared compact MySQL collector is `littlex/primary-rtt/compact_proxy.py`: same validated protocol completion parser, one command event plus response-received/delivered events, no per-row/per-frame output. Extract using exact request SHOW SESSION STATUS bounds on the uniquely identified connection; require every command completion, command count equality with Questions, CALL count equality with Com_call_procedure, sequential complete responses and correctness/state gates. Initialization/status probes are excluded. Forwarding/parser provenance, SQL catalog, raw commands, cleanup and instrumentation restoration are retained.

TPC-C pilot: `python tpcc/primary-rtt/run.py --pilot --out NEWDIR`. One GC-name direct/SP pair, fresh state per phase, 10 mutating warmups and 30 measured requests, short shared host lease. Full controller runs 69 runnable configurations plus 57 explicit compiler-stage-failure entries for 126 terminal cells; delays 0/2/10 ms. Every accepted pair preserves evolving outputs, targeted mutable state and global counts. Original900 reference runs retain full eight-table model gates and reject observed state failures; no rejected reference contributes an accepted median. Estimated representative controller cost is comparable to the prior 15–25 minute application matrix plus compact trace extraction; each case pair yields the host lease. No separate fresh server-only matrix is needed.
