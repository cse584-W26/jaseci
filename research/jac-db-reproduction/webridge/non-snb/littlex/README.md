## Primary SQL round-trip measurements

The primary comparison uses the median of each request's **sum of top-level SQL command round-trip durations**. The compact proxy timestamps the complete incoming MySQL command and the final complete response forwarded/drained to the client socket. A stored-procedure CALL contributes one outer duration, including all its result sets. The exact request SHOW SESSION STATUS boundaries exclude status counters and connection initialization. Same-request command and CALL counts are checked against the timer's session counters, and every executable cell retains its independent response and committed-business-state gates.

`primary-rtt/complete-final/` runs the complete 360-cell latency matrix and 120 original-reference cells in lease-bounded groups. `normalized-rtt-results.json` and `rtt-cycle-evidence.json` publish completed groups during collection. Each accepted normalized row points to the request-level RTT operations, complete compact trace, SQL catalog, source oracle and state gate. The compact parser's source provenance and frozen collector snapshots are retained under `primary-rtt/`.
