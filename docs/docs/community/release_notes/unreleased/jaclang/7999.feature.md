- **Decoded-GTI process cache (`JAC_GTI_CACHE`, default off)**: the read-side resolver can now serve topology-index decodes from a process-level LRU keyed by root id and validated by a blake2b digest of the blob, eliminating the per-request re-decode of foreign-root GTI blobs on cross-root traversals (and the local root's decode). Digest validation makes stale hits impossible; cached entries are frozen (mutators raise), and write hooks keep decoding private copies. Cap via `JAC_GTI_CACHE_SIZE` (default 1024 roots; malformed values fail loud). toml mirror: `[run] gti_cache`.
