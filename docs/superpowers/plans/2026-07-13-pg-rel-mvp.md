# PostgresRelBackend MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** L3 backend `postgres-rel` where hops are answered by an indexed SQL edges table instead of GTI blob decode; KV backend untouched.

**Architecture:** `PostgresRelBackend(PostgresBackend)` subclass adds one `edges` table maintained inside `apply()` from changeset intents, advertises `topology_sql` capability, and implements `resolve_hop_sql`. One capability-gated early branch in `resolve_hop` dispatches to it (byte-identical when capability absent). Spec: `docs/superpowers/specs/2026-07-13-pg-rel-backend-design.md`.

**Tech Stack:** jac (fork worktree `/home/aaron/Dev/Research/DatabaseResearch/JaseciFork-pgrel`), psycopg3 pool, local PG db `jactest_rel` for tests.

**Verified ground truth (do not re-derive):**

- `TieredMemory.capabilities()` delegates to `self.l3.capabilities()` (`runtimelib/impl/memory.impl.jac:1970-1972`); base `Memory.capabilities` returns `set()`.
- `EdgeDir: IN=1, OUT=2, ANY=3` (`jac0core/constant.jac:115`); `hop.edge_type`/`hop.node_type` are type-NAME strings or None; `hop.direction` the int.
- `PostgresBackend.delete(id)` is a deliberate NO-OP (issue #6587) -- durable deletes only via apply intents. So NO delete override; edge-row sweeps live in the apply path only.
- `WriteIntent`: `{op, anchor, fields, edges_added: list[UUID], edges_removed: list[UUID], depends_on, cas_version}`; `staged()` = 6 buckets by op.value (creates first, deletes last: EDGE_DELETE=4 before NODE_DELETE=5).
- `_pg_apply_one(conn, intent)` (`postgres.impl.jac:570-576`): deletes → `DELETE FROM anchors`; else `_pg_merge_write`. This is the ONE function the subclass wraps.
- Pool is process-cached by `pg_pool::{dsn}::{min}::{max}` -- shared with KV backend on same DSN; rel schema bootstrap needs its own once-per-process guard.
- Test conventions (`scale/tests/data/test_postgres_backend.jac`): `glob _DSN = os.environ.get('POSTGRESQL_URI', 'postgresql:///jactest')`, `_fresh()` truncates tables, `_cold()` second instance, phase-prefixed test names (`"reads: …"`), duck-typed `any` anchors, raw psycopg for verification.
```jac
"""PostgresRelBackend bodies: KV backend + relational edges index table.

The edges table replaces the per-root GTI blob as the topology answer-er:
one row per EdgeAnchor, maintained inside apply()'s transaction from
changeset intents (no topo_utils hooks, no JAC_TOPOLOGY_INDEX coupling).
Consistency rule: edges row exists iff the edge's anchors row exists."""

import threading;

glob _pgrel_schema_lock = threading.Lock(),
     _pgrel_schema_done: set[str] = set();

glob _REL_SCHEMA_SQL: list[str] = [
         """
    CREATE TABLE IF NOT EXISTS edges (
        edge_id       TEXT PRIMARY KEY,
        source        TEXT NOT NULL,
        target        TEXT NOT NULL,
        edge_type     TEXT NOT NULL,
        is_undirected BOOLEAN NOT NULL DEFAULT FALSE,
        seq           BIGINT GENERATED ALWAYS AS IDENTITY
    )
    """,
         "CREATE INDEX IF NOT EXISTS idx_edges_src ON edges (source, edge_type, seq)",
         "CREATE INDEX IF NOT EXISTS idx_edges_tgt ON edges (target, edge_type, seq)"
     ];


impl PostgresRelBackend.postinit -> None {
    super.postinit();
    # Pool may be process-cached by the KV backend on the same DSN, so the
    # rel schema needs its own once-per-process bootstrap.
    if self.dsn not in _pgrel_schema_done {
        with _pgrel_schema_lock {
            if self.dsn not in _pgrel_schema_done {
                conn: any = self.__pool__.getconn();
                try {
                    for stmt in _REL_SCHEMA_SQL {
                        conn.execute(stmt);
                    }
                    conn.commit();
                } finally {
                    self.__pool__.putconn(conn);
                }
                _pgrel_schema_done.add(self.dsn);
            }
        }
    }
}


"""Advertise SQL topology; JAC_TOPOLOGY_SQL=0 turns the resolver branch off
while keeping rel storage (ablation: rel-storage-with-GTI-hops)."""
impl PostgresRelBackend.capabilities -> set[str] {
    import os;
    env = os.environ.get("JAC_TOPOLOGY_SQL");
    if env is not None and env.lower() in ("0", "false", "no", "off") {
        return set();
    }
    return {'topology_sql'};
}
```

```jac
"""Answer one hop from the edges table. Returns None on any failure so the
resolver falls back to the blob/walk ladder (never raises into a request).
direction: EdgeDir ints (IN=1, OUT=2, ANY=3). Ordered (slc) variant returns
first-seen creation order (GROUP BY target ORDER BY MIN(seq)) matching
TopologyIndex.resolve_chain_ordered; slice applied here."""
impl PostgresRelBackend.resolve_hop_sql(
    current_ids: set[UUID],
    edge_type: (str | None),
    node_type: (str | None),
    direction: int,
    slc: (slice | None) = None
) -> (set[UUID] | list[UUID] | None) {
    if not current_ids {
        return [] if slc is not None else set();
    }
    ids = [str(u) for u in current_ids];
    type_join = " JOIN anchors a ON a.id = dst.out_id AND a.arch_type = %s"
        if node_type is not None else "";
    etype_pred = " AND e.edge_type = %s" if edge_type is not None else "";

    def _leg(src_col: str, dst_col: str, undirected_only: bool) -> str {
        upred = " AND e.is_undirected" if undirected_only else "";
        return (
            f"SELECT e.{dst_col} AS out_id, e.seq AS seq FROM edges e "
            f"WHERE e.{src_col} = ANY(%s){etype_pred}{upred}"
        );
    }

    legs: list[str] = [];
    params: list = [];
    def _add(src_col: str, dst_col: str, undirected_only: bool) {
        legs.append(_leg(src_col, dst_col, undirected_only));
        params.append(ids);
        if edge_type is not None {
            params.append(edge_type);
        }
    }
    if direction == 2 {          # OUT
        _add('source', 'target', False);
        _add('target', 'source', True);   # undirected traversable backwards
    } elif direction == 1 {      # IN
        _add('target', 'source', False);
        _add('source', 'target', True);
    } else {                     # ANY = 3
        _add('source', 'target', False);
        _add('target', 'source', False);
    }
    inner = " UNION ALL ".join(legs);
    sql = (
        f"SELECT dst.out_id FROM ({inner}) dst{type_join} "
        "GROUP BY dst.out_id ORDER BY MIN(dst.seq)"
    );
    if node_type is not None {
        params.append(node_type);
    }
    try {
        conn: any = self.__pool__.getconn();
        try {
            conn.autocommit = True;
            rows: any = conn.execute(sql, tuple(params)).fetchall();
        } finally {
            conn.autocommit = False;
            self.__pool__.putconn(conn);
        }
        self.rel_hop_count += 1;
        ordered = [UUID(r[0]) for r in rows];
        # Exclude frontier self-echo? No: GTI includes self-loops; keep parity.
        if slc is not None {
            return ordered[slc];
        }
        return set(ordered);
    } except Exception as e {
        self.rel_hop_fallback_count += 1;
        logger.debug(f"PostgresRelBackend.resolve_hop_sql fallback: {e}");
        return None;
    }
}
```
